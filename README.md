## Mateus Aleixo

MSc Data Science at the University of Aveiro. I build machine learning systems for
industrial settings, with a particular interest in **uncertainty quantification**:
making a model state how confident it is in a way that can actually be trusted, and
then deploying the result.

### Selected work

A series applying one principle, *a prediction without a trustworthy confidence
statement is not a decision aid*, across three modalities:

| repo | what it does |
|---|---|
| [**conformal-rul**](https://github.com/mateus-aleixo/conformal-rul) | Remaining-useful-life prediction for turbofan engines with calibrated intervals. PyTorch, ONNX, live on AWS Lambda via Terraform and OIDC-authenticated CI. |
| [**conformal-seg**](https://github.com/mateus-aleixo/conformal-seg) | Defect segmentation whose masks provably miss at most a set fraction of defect pixels. torchvision fine-tune, ONNX export with a parity check. |
| [**conformal-rag**](https://github.com/mateus-aleixo/conformal-rag) | RAG over maintenance manuals that abstains at a calibrated error rate. Framework-free agent, prompt-injection suite enforced in CI. |

Also here:
